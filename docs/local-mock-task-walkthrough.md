# 本地合成任务试用

该流程用于隔离环境，规则模型不调用付费供应商，MCP 返回合成文本；PI 的文件和 Bash 工具仍实际执行。先阅读 [SECURITY.md](../SECURITY.md)，不要使用有敏感文件或不可信任务的主机。

1. 从仓库根运行 `bash scripts/start.sh --mock`，打开本机 Web。
2. 使用单独测试账号和工作区。按 [Mock 指南](../mock/README.md)配置地址 `http://127.0.0.1:18302/v1`、model ID `mock` 和公开测试 token，通过连接测试后保存。
3. 为测试员工选用该模型并明确允许测试用户的 Web 使用范围。无需给模型提供真实渠道或业务凭据。
4. 发送精确输入 `你好`，再发送 `帮我写一个md文章`。规则按固定输入工作，不是通用模型；未匹配输入可能返回 `mock_rule_not_matched`。
5. 通过任务页核对 Task、Run、实际工具过程和最终结果。不能把规则模型的一句“完成”当作文件已生成；以真实执行结果为依据。
6. 需要 MCP / Skill 权限试用时，另按 Mock 指南显式创建资源与能力包，启动合成服务本身不产生授权。

所有测试记录保留在所选本地数据 / 状态目录，停止服务不会自动删除。清理或重置数据需明确确认，请勿将这些本地运行记录提交到代码仓库。
