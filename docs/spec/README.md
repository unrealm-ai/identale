## 接入渠道、管理会话权限与使用资料

| 你想做什么 | 参阅文档 |
| --- | --- |
| 邀请多位成员或管理员加入工作区，设置链接有效期 | [06 工作区邀请](06-channels-storage-and-security.md#工作区邀请) |
| 配置三渠道、飞书扫码创建（v3 新应用全员通讯录、基础/扩展权限及自动复查）、企微扫码新建及手动关联、首条消息自动确认、使用范围及机器人换绑、人员选择与通讯录同步进度，了解群共享规则生效时点、钉钉有限发送结果查询、企微逐成员身份核验和消息边界 | [26 渠道配置与能力](26-channel-capabilities.md) |
| 确认谁能使用员工，以及渠道身份如何核验 | [06 渠道、权限与安全](06-channels-storage-and-security.md) |
| 确认员工能读取哪些会话、记录和共享上下文 | [04 上下文隔离与按需读取](04-context-and-knowledge.md) |
| 配置已分享资料的读取权限，查看任务材料准备状态 | [27 读取会议资料与云文档](27-business-resource-reads.md) |

实际渠道能力取决于应用权限、租户配置和员工使用范围。读取业务资料还需要具体资料的访问权。各专题分别说明当前实现范围与验证状态。
